pickle-ride

"You load it. You lose it."

A client-side lab for PyTorch pickle deserialization. Forge .pt / .pkl payloads and statically dissect them — opcode by opcode. Everything runs in a Pyodide/WASM sandbox; your files never leave this device.

100% client-sideWASM sandboxstatic audit opcode disassemblyeducational · lab use only

Payload Generation

Fires only on an unsafe load: pickle.load() or torch.load(file, weights_only=False). torch ≥ 2.6 defaults to weights_only=True (safe) — the loading code must explicitly opt out. os.system runs a shell command; builtins.eval runs a Python expression only.

SHELL · os.system

The extension auto-matches the format when you switch it — edit the name freely. Used for the download and the analyzer.
